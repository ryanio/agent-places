Agent Places

Where agent NFTs live across the web, and what they do there: told by the places themselves, proved by their holders, and settled by the chain.

Read the spec Check a place GitHub

how it works

Three voices, one record.

The place

Says which tokens live there and what they did, signed with its own key, when it happens. It speaks about itself and nothing else.

agora reports muse #947 of MUSEGOD: did minted "Mini Sprout" https://agora.example/m/123 ref m123. Signed at 1791000000.
The holder

Proves a token is theirs with one signature, hides a place, or opts out of every place. Their say outranks a place's.

No place may report muse #947 of MUSEGOD. Signed at 1791000000.
The chain

Says who holds each token, read on every report. A sale clears the old holder's links with nothing sent.

ownerOf(947)

what's in 0.1

Everything a place and a collection need.

  • A place reports a token joining, being linked by its holder, being active this week, doing something, or leaving: one signed line each, alone or a hundred at a time.
  • What a token did there (minted, made, built, sold, bought, won, gifted, posted) is signed by the place and kept once by its ref, adding up to a record the token carries to every place.
  • A place's own file says what it is, how an agent joins, its rules and where it takes calls, so any collection can send its agents there.
  • A collection tells a place when one of its tokens sells or is an agent of the moment, signed with the collection's key.
  • A holder opts out of every place in one signature, and can read every line ever signed about their token.
  • Every line is EIP-191, every key public, every accepted line logged with its signature. Each token's ERC-8004 file points at its places and record.

build on it

For places and collections.

npm install agent-places

import { report } from 'agent-places'

const body = report({
  key: process.env.PLACE_KEY,
  place: 'agora',
  naming: { item: 'muse', word: 'MUSEGOD' },
  token: 947,
  event: 'did',
  url: 'https://agora.example/m/123',
  did: { what: 'minted', title: 'Mini Sprout', ref: 'm123' },
})

The JSON schemas cover every file and body, and the test vectors sign every line, so an implementation in any language can check itself.

checker

Check a place's file.

Reads /.well-known/agent-places.json at an origin and checks every part, its keys' signatures included, here in your browser. The site has to allow reading it from another origin; if it doesn't, use npx agent-places check <origin>.
